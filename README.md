# PetraVoice — Hyper-Local AI Voice Mobility Assistant

Jordan 2076 Hackathon · Aqaba 2076 Track (powered by Petra Ride) · Team **PromptRiders** · Sub-Track 02: AI Voice Mobility Assistant

| Part       | Path                      | Stack                                        |
| ---------- | ------------------------- | -------------------------------------------- |
| Frontend   | [`frontend/`](frontend/)  | React + Tailwind + MediaRecorder + Leaflet   |
| Backend    | [`backend/`](backend/)    | Node.js + Express + SQLite + Whisper + LLM   |

Quick start: `cd backend && npm install && npm run dev` (port 8000), then `cd frontend && npm install && npm run dev` (port 5173). See [backend/README.md](backend/README.md) and [frontend/README.md](frontend/README.md).
